RemoteControl — Page statique

Ouvrir index.html pour consulter la page.

Publication : créer un dépôt séparé remotecontrol-site et y déposer index.html, style.css, .nojekyll et assets/. Dans Settings > Pages, sélectionner Deploy from a branch, puis main et / (root).

Le lien de téléchargement réel reste à renseigner dans index.html. Le bouton actuel mène au profil GitHub du créateur. Aucun autre dépôt ne doit être modifié.
