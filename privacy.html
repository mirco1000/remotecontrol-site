Politique de confidentialité

Dernière mise à jour : 20 octobre 2026

Application RemoteControl

RemoteControl ne collecte aucune donnée personnelle. Le développeur ne collecte, ne conserve, ne vend et ne partage aucune donnée personnelle par l’intermédiaire de l’application.

Publicités et statistiques

L’application ne contient pas de publicités et n’intègre aucun outil de suivi publicitaire ou de mesure d’audience.

Photos, vidéos et musique

Les fonctions de partage de médias de l’application ne constituent pas une collecte de vos fichiers par le développeur. Le développeur ne récupère pas vos photos, vidéos ou musiques.

Site de présentation

Ce site ne comporte ni formulaire de collecte de données, ni publicité, ni outil de statistiques ajouté par le développeur. Votre choix de langue (français ou anglais) est enregistré uniquement dans le stockage local de votre navigateur, sous la clé remotecontrol-language. Vous pouvez le supprimer dans les réglages de votre navigateur.

Hébergement GitHub Pages

Le site est hébergé par GitHub Pages. GitHub indique enregistrer l’adresse IP des visiteurs pour assurer la sécurité du service. Ce traitement relève de GitHub, et se distingue du fonctionnement de l’application RemoteControl.

Consultez la politique de confidentialité de GitHub et la documentation GitHub Pages.

Liens externes

Les liens vers GitHub conduisent vers un service tiers régi par sa propre politique de confidentialité.

Évolution de cette politique

Cette page sera mise à jour si les pratiques de l’application ou du site changent. La date de mise à jour figure en haut de cette page.

REMOTECONTROL · PRIVACY

Privacy Policy

Last updated: October 20, 2026

RemoteControl application

RemoteControl does not collect personal data. The developer does not collect, retain, sell or share personal data through the application.

Advertising and analytics

The application contains no advertisements and includes no advertising trackers or analytics tools.

Photos, videos and music

The app’s media sharing features do not involve the developer collecting your files. The developer does not receive your photos, videos or music.

Promotional website

This website has no data collection forms, advertisements or analytics tools added by the developer. Your language preference (French or English) is stored only in your browser’s local storage under the key remotecontrol-language. You can remove it through your browser settings.

GitHub Pages hosting

This website is hosted on GitHub Pages. GitHub states that it logs visitors’ IP addresses for service security. This processing is performed by GitHub and is separate from the operation of the RemoteControl application.

See the GitHub Privacy Statement and the GitHub Pages documentation.

External links

Links to GitHub lead to a third-party service governed by its own privacy policy.

Policy changes

This page will be updated if the app’s or website’s practices change. The revision date appears at the top of this page.
