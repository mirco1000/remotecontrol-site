Connexion au téléviseur

Connectez votre téléphone et votre TV au même réseau Wi-Fi. Allumez la TV, ajoutez-la dans RemoteControl et acceptez la demande d’autorisation ou saisissez le code affiché.

La TV n’apparaît pas ?

Vérifiez que l’accès au réseau local est autorisé dans les réglages de votre appareil. Évitez les réseaux invités et vérifiez que la TV autorise le contrôle réseau.

Signaler un problème

Indiquez le modèle de votre téléphone, la version du système, la marque et le modèle de votre TV, ainsi que les étapes pour reproduire le problème.

Ouvrir une demande sur GitHub ↗

Un compte GitHub est nécessaire. Les demandes sont publiques : ne publiez aucun mot de passe ni donnée personnelle.

Support

Connecting to your TV

Connect your phone and TV to the same Wi-Fi network. Turn on the TV, add it in RemoteControl, and accept the authorization request or enter the code shown.

TV not appearing?

Check that local network access is enabled in your device settings. Avoid guest networks and check that the TV allows network control.

Report a problem

Include your phone model, operating system version, TV brand and model, and the steps to reproduce the problem.

Open a support request on GitHub ↗

A GitHub account is required. Requests are public: do not include passwords or personal information.

Privacy Policy

Asistencia

Conectar el televisor

Conecta el teléfono y el televisor a la misma red Wi-Fi. Enciende el televisor, añádelo en RemoteControl y acepta la autorización o introduce el código mostrado.

¿No aparece el televisor?

Comprueba que el acceso a la red local esté permitido en los ajustes de tu dispositivo. Evita las redes de invitados y permite el control de red en el televisor.

Informar de un problema

Indica el modelo del teléfono, la versión del sistema, la marca y el modelo del televisor y los pasos para reproducir el problema.

Abrir una solicitud en GitHub ↗

Se necesita una cuenta de GitHub. Las solicitudes son públicas: no incluyas contraseñas ni datos personales.

Política de privacidad

Support

Verbindung zum Fernseher

Verbinde dein Smartphone und deinen Fernseher mit demselben WLAN. Schalte den Fernseher ein, füge ihn in RemoteControl hinzu und bestätige die Freigabe oder gib den angezeigten Code ein.

Fernseher wird nicht angezeigt?

Prüfe in den Geräteeinstellungen den Zugriff auf das lokale Netzwerk. Vermeide Gastnetzwerke und erlaube die Netzwerksteuerung am Fernseher.

Problem melden

Nenne dein Smartphone-Modell, die Betriebssystemversion, Marke und Modell des Fernsehers und die Schritte zum Reproduzieren des Problems.

Supportanfrage auf GitHub öffnen ↗

Ein GitHub-Konto ist erforderlich. Anfragen sind öffentlich: Teile keine Passwörter oder persönlichen Daten.
